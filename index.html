Cadangan & Pemulihan Data (Backup & Restore)

Amankan data penilaian dan karyawan Anda. Unduh file cadangan secara berkala agar data tidak hilang saat HP di-reset atau browser dibersihkan.

1. Ekspor Cadangan (Backup)

Mengunduh seluruh database aplikasi (data karyawan dan riwayat harian) ke dalam satu file berformat JSON.

2. Pulihkan Data (Restore)

Unggah file cadangan JSON yang sebelumnya pernah diunduh untuk mengembalikan seluruh data Anda seketika.
